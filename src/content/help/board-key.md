---
title: Как утилита узнаёт борт
---
## Коротко
Борт = полётник (его уникальный ID из лога) + имя борта (Craft name). Спорные случаи решаешь ты.

## Подробно
С Betaflight 2025.12 в заголовок лога пишется `DeviceUID` — уникальный номер процессора полётника. По нему утилита отличает два квадрика на одинаковых полётниках (раньше они сливались в один борт по модели платы).

Утилита спрашивает тебя, когда по логу не решить:
- **полётник встречается впервые** — новый борт или уже знакомый (например, борт из старых логов без ID);
- **тот же полётник, другое имя** — ты переименовал борт или переставил полётник в новую раму.

**Полётник переехал в новую раму** — это новый борт: у другой рамы другие пропы, моторы и резонансы, сравнивать её логи со старой рамой нельзя. История старого борта сохраняется, а у нового видно «тот же полётник, что был у …». То же можно сделать кнопкой «Полётник переехал…» у борта.

Логи Betaflight 4.5 ID полётника не содержат — для них борт узнаётся по-старому, по имени или плате.

## Для тюнера
- Задай Craft name каждому борту (`set craft_name = …`) — он попадает в лог, и путаницы меньше даже на старых прошивках.
- Сессии, сохранённые до этого обновления, разложены по ID полётника автоматически: если под одним именем жили два полётника, борт разделён на два, ничего не удалено.
