## Коротко
Список логов в файле, их дубли и испорченные участки.

## Подробно
Полный дамп флешки — это несколько логов подряд, каждый начинается с маркера `H Product:Blackbox flight data recorder`. Утилита находит их сама, ищет повтор данных (заворот адреса флешки) и стёртые области. Файл читается кусками — даже 132 МБ не грузятся в память целиком.

## Для тюнера
Длительность в списке — быстрая оценка по первому и последнему кадру; точная появится после открытия лога.
