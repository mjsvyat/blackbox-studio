# Blackbox Studio

Локальная утилита разбора и настройки квадрокоптера по блэкбоксу Betaflight.
Без сервера в облаке, без аккаунтов, без телеметрии.

## Запуск

```bash
npm install          # один раз
npm run dev          # http://localhost:5181, подсказки .md подхватываются на лету
npm run build        # dist/index.html — один файл, открывается двойным кликом без сервера
npm test             # все тесты (включая дамп 132 МБ, ~20 с)
npm run test:fast    # без большого дампа
```

Открой файл кнопкой «Открыть лог…» или перетащи его в окно: `.bbl`, `.bfl`, `.txt`,
в том числе полный дамп флешки.

## Что где

- `PLAN.md` — архитектура, этапы, что нельзя посчитать надёжно.
- `CLAUDE.md` — инструкция для Claude на будущие сессии.
- `src/config/analysis.json` — все пороги светофора и маски «чистого полёта».
- `src/content/help/*.md` — тексты подсказок «?». Формат:

  ```markdown
  ---
  title: Заголовок
  ---
  ## Коротко
  одна строка
  ## Подробно
  абзац без формул
  ## Для тюнера
  что крутить и чем платим
  ```

  Ссылка на термин глоссария — `[[текст|id]]`, термины — в `src/content/glossary.md`
  (`## Термин {#id}`). Новый файл в `help/` подхватывается автоматически; чтобы кнопка
  «?» появилась у нового элемента интерфейса, нужен его id в коде.
- `src/i18n/ru.ts` — все строки интерфейса.
- `docs/PROMPT.md` — исходное ТЗ.
- `tests/fixtures/` — настоящие логи для тестов (большой дамп через Git LFS: после клонирования `git lfs pull`).
