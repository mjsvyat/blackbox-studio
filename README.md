# Blackbox Studio

Локальная утилита разбора и настройки квадрокоптера по блэкбоксу Betaflight.
Без сервера в облаке, без аккаунтов, без телеметрии.

## Запуск

```bash
npm install          # один раз
npm run dev          # http://localhost:5181, подсказки .md подхватываются на лету
npm run build        # dist/index.html — один файл, открывается двойным кликом без сервера
npm test             # все тесты (включая дамп 132 МБ, ~20 с)
npm run test:fast    # без большого дампа
```

CI (GitHub Actions) на каждом PR гоняет типы, тесты без большого дампа и сборку; готовый
`dist/index.html` лежит в артефактах прогона (`blackbox-studio-dist`). Полный прогон с дампом
132 МБ — только локально: `git lfs pull && npm test`.

Открой файл кнопкой «Открыть лог…» или перетащи его в окно: `.bbl`, `.bfl`, `.txt`,
в том числе полный дамп флешки.

## Что где

- `PLAN.md` — архитектура, этапы, что нельзя посчитать надёжно, что пробовали и почему не сработало.
- `CLAUDE.md` — инструкция для Claude на будущие сессии.
- `src/config/analysis.json` — все пороги светофора и маски «чистого полёта».
- `src/content/help/*.md` — тексты подсказок «?». Формат:

  ```markdown
  ---
  title: Заголовок
  ---
  ## Коротко
  одна строка
  ## Подробно
  абзац без формул
  ## Для тюнера
  что крутить и чем платим
  ```

  Ссылка на термин глоссария — `[[текст|id]]`, термины — в `src/content/glossary.md`
  (`## Термин {#id}`). Новый файл в `help/` подхватывается автоматически; чтобы кнопка
  «?» появилась у нового элемента интерфейса, нужен его id в коде.
- `src/i18n/ru.ts` — все строки интерфейса.
- `docs/PROMPT.md` — исходное ТЗ.
- `cases/INC-xxxx-*/` — разобранные инциденты; каждый — регрессионный тест (`tests/cases`).
- `tests/fixtures/` — настоящие логи для тестов (большой дамп через Git LFS: после клонирования `git lfs pull`).

## Цикл работы

1. Открой лог → «Сводка» (светофор) → вкладки с причинами.
2. «Настройка» — советы с номером правила, цифрой, риском и готовым CLI. Сначала механика,
   не больше двух изменений за полёт.
3. Песочницы: «Фильтры» (точный пересчёт), «Рейты» (точный пересчёт), «PID / step» (прогноз
   модели с полосой — проверяй полётом).
4. «Сессии и сравнение» → «Сохранить как сессию» (до полёта с новыми настройками), слетай,
   сохрани второй лог — сравнение «было / прогноз / стало», что из плана применено.
5. Стало хуже — ⚠ «Сообщить о проблеме» → «Скачать папку случая» → распакуй в `cases/` и
   попроси Claude разобрать (порядок — в `CLAUDE.md`). Откат настроек — ↩.
6. «Отчёт HTML» в шапке — один файл со всем разбором.
