# Знания из чата «Blackbox 2.0» (t.me/blackbox_two)

Сообщество разбора блэкбоксов Betaflight, ~650 участников. Здесь — выжимка закреплённых
инструкций (прочитаны 2026-10-12) и что из них следует для Blackbox Studio. Видео-инструкции
(PID, фильтры для начинающих, теория Россера, Feedforward, AM32, автотюн) через веб не
читаются — их содержание сюда не входит.

Источники: правила и оглавление — [32681](https://t.me/blackbox_two/32681); запись лога —
[12](https://t.me/blackbox_two/12); тест моторов — [6130](https://t.me/blackbox_two/6130);
«примитивный алгоритм» — [37268](https://t.me/blackbox_two/37268); «Drone Tune 26» —
[Google Doc](https://docs.google.com/document/d/1iFz9VZOkGuT1n8UnlZHkYVp9tYomGp3iNUDC6tw-7C4).
Chirp-инструмент разработчика BF — [pichim/bf_controller_tuning](https://github.com/pichim/bf_controller_tuning).
Бесплатный форк PIDToolBox — [PIDscope](https://github.com/dzikus/PIDscope).

## 1. Что требуют от лога на разбор

- Последняя стабильная прошивка; базовая настройка без пресетов (кроме пресета линка); не
  переносить diff со старых версий вслепую.
- **RPM-фильтр включён** (bidirectional DShot, правильное число полюсов).
- **Пресет сглаживания линка** под тип и частоту пакетов (например ELRS 150 Гц), в аппаратуре —
  выключить ADC-фильтр.
- Debug: `gyro_scaled` на 4.5 (на более новых не нужен); для фильтров — `FFT_FREQ`
  (видно, где стоят динамические нотчи) или `CHIRP` при сборке с chirp.
- Частота лога: **≥ 2 кГц для фильтров**, **≥ 1 кГц для PID**.
- Первый полёт 20–30 с → **проверить температуру моторов** (не должны обжигать). Странные
  звуки или тряска — сразу сажать.
- **Полёт для фильтров**: висение ровно 5 с; газ плавно от 0 до 100 % несколько раз (или
  шагами по 10 % от висения до полного, по 3–5 с на шаге); покачивания по питчу и роллу;
  флипы и роллы на 180/360°.
- **Полёт для PID**: в ANGLE, покачать по питчу/роллу 10–15 с, сесть (или chirp).
- К логу — описание сетапа: полётник, ESC и их прошивки, рама, моторы (размер, KV), пропы,
  фото; и **конкретная жалоба или цель**.

## 2. Тест моторов на столе (электрошум гироскопа)

Пропы сняты, `set blackbox_mode = MOTOR_TEST`, коптер на мягком (подушка, чтобы рама не
резонировала), во вкладке «Моторы» по очереди раскрутить каждый мотор 0→100→0 %, потом все
вместе. После — вернуть `blackbox_mode = NORMAL`. Цель — увидеть шум гироскопа, который
идёт от электрики и моторов, без аэродинамики.

## 3. Подготовка ESC и борта («Drone Tune 26»)

- Прошить ESC последней прошивкой, сохранив прежние мощности и углы.
- **Несущая частота ESC фиксированная**: 48 кГц для дронов меньше 7", 24 кГц — для 7" и больше.
  На AM32 (32-бит) нижнюю и верхнюю частоту ставить одинаковыми.
- **Динамический холостой ход** (`dyn_idle_min_rpm`) выставить по размеру дрона — это прямое
  задание оборотов на нуле газа.
- Ориентация платы и гироскопа, арминг при 180°, порты, каналы — до записи логов.
- Калибровка датчика тока по заряднику (факультативно, на настройку не влияет).

## 4. Стратегия настройки, которую рекомендует чат

1. Механика: гнутые пропы, болтающиеся детали — до любой настройки.
2. Пресет сглаживания линка и ADC-фильтр в аппаратуре.
3. Записать лог, посмотреть шум; **отключить все фильтры, какие можно**, ради меньшей фазовой
   задержки PID. Исключение: **не отключать gyro LPF2, если частота PID-цикла ниже частоты
   гироскопа** (`pid_process_denom` > 1).
4. Оставшиеся фильтры поставить на частоты найденного шума: RPM, динамический нотч на раму и
   **обязательно — фильтры D-term**.
5. **Баланс P/D**: серия логов, где меняется один параметр (обычно D по 1 пункту, 6 логов), а
   остальное неизменно. Критерий — **минимальная задержка step response** (а не перерегулирование).
6. **Главный множитель**: снова минимальная задержка при отсутствии осцилляций. Мелким дронам —
   меньше, крупным — больше, пока PID-графики не станут читаемыми.
7. Потом — нюансы.

Стартовая точка серии D («Drone Tune 26», слайдеры Simplified): FF, D max и I — влево до
конца; мастер −2 пункта; D −3 пункта; затем 6 логов, каждый раз D +1 пункт (менять из OSD или
конфигуратора).

## 5. Что это значит для Blackbox Studio

| Из чата | Что сейчас в утилите | Что сделать |
|---|---|---|
| Фильтры ≥ 2 кГц, PID ≥ 1 кГц | порог «редкий лог» 1.6 кГц только для фильтров | согласовать протокол и подписи |
| Полёт для фильтров: ступени газа 0→100 % | протокол A2 проверяет «хватает ли манёвров» | проверять покрытие газа по бинам 0–100 % |
| `debug_mode = FFT_FREQ` | не используется | читать центры дин. нотча из debug — **прямая проверка нашей модели дин. нотча** |
| Тест моторов `MOTOR_TEST` | лог без полёта отбрасывается как «земля» | режим «стендовый тест»: шум гиро от мотора/оборотов, по моторам |
| Не отключать LPF2 при denom > 1 | нет такого правила | правило советчика + предупреждение в песочнице |
| D-фильтры обязательны | нет запрета их выключать | предупреждение, если в песочнице D-LPF выключены |
| Критерий P/D — мин. задержка step response | советчик смотрит в основном на перерегулирование | метрика задержки как цель; **серия логов D** → выбор лучшего |
| Дин. холостой ход по размеру | `dyn_idle_min_rpm` в заголовке не проверяется (у пользователя 0) | правило «дин. ХХ выключен» с рекомендацией по классу борта |
| Несущая ESC 48/24 кГц | ESC не читается | пункт чек-листа (не по логу) |
| Пресет линка, ADC выкл. | нет | эвристика по шуму/ступенькам setpoint и FF-дрожи + пункт чек-листа |
| Температура моторов после 20–30 с | отметка в инциденте | обязательный вопрос в протоколе после изменения D/фильтров |
