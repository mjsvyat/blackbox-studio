Номер сборки — как в релизе (`v1.08.26`); внутри `package.json` — semver (`1.8.26`).

## v1.08.26

Первая сборка для Windows: установщик, portable-версия и веб-версия одним файлом.

**Программа для Windows**
- Окно программы вместо вкладки браузера: ярлык на рабочем столе и в «Пуске», данные в
  `%APPDATA%\Blackbox Studio`, работает без интернета.
- Полётник по USB работает и в программе: выбор COM-порта в окне Windows, переподключение после
  перезагрузки полётника.
- Версия программы — в шапке окна, в отчётах HTML и экспорте кампании.

**Автотюн**
- Кнопка «Автотюн»: разобрали лог → записали на борт по USB → слетал → снова разобрали.
- Не душит борт: одно изменение за полёт, фильтры зажимаются только при горячих моторах, ниже
  стартовых настроек серии сильно не уходит, «нравится» — ничего не трогает.
- Спрашивает про пропы: с побитыми по полёту ничего не меняет, со сколами не судит по шуму; сам
  замечает, если шум до фильтров вырос (похоже на проп или механику).
- Изменение сделало хуже (по цифрам или по ощущению) — следующий шаг откат.

**Разбор лога**
- Декодер блэкбокса Betaflight кадр в кадр с эталоном; полный дамп флешки, заворот W25N01GV на
  64 МиБ, битые куски и дубли логов.
- Сводка-светофор, шумы и спектрограммы, точная модель фильтров с песочницей, step response и
  модель оси с прогнозом, рейты, моторы и питание, полёт и события, частотный анализ и chirp.
- Подсказка «?» у каждой цифры, глоссарий, отчёт HTML одним файлом.

**Настройка**
- Советчик с номерами правил и готовым CLI; сессии и сравнение «было → прогноз → стало».
- Кампании настройки: протокол тестового полёта, отметки пилота, точность прогнозов и правил,
  предложения порогов, экспорт кампании.
- Инциденты и откат; несколько бортов по ID полётника, классы бортов, перенос настроек.

**Полётник по USB**
- Сводка, скачивание и стирание флешки; чтение настроек; запись совета на борт с бэкапом и откатом —
  только по нажатию и только на незаармленный борт.

**Видео из очков**
- MOV/MP4 рядом с графиками, синхронизация по часам и по движению кадра.

**Известные ограничения**
- Программа без цифровой подписи — SmartScreen предупредит при первом запуске («Подробнее» →
  «Выполнить в любом случае»).
- Работа с настоящим полётником по USB проверена на эмуляторе; на железе — по чек-листу в `PLAN.md`.
- Сессии из браузерной версии переносятся вручную: «Экспорт в файл» → «Импорт из файла…».
